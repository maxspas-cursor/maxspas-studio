# КиберЩит — веб-стол

Онлайн-комната по грантовой заявке «КиберЩит: Хроники цифровой безопасности».

Ведущий открывает стол на компьютере. Игроки заходят с телефонов по коду в той же Wi‑Fi сети. Ночные действия скрыты; ведущий роли и карты не видит.

## Запуск

```bat
start.bat
```

или:

```bat
py -3 server.py --open
```

Откроется `http://127.0.0.1:8765`. В консоли будет ссылка для телефонов вида `http://192.168.x.x:8765`.

Если телефон не открывает страницу — в брандмауэре Windows разрешите Python для частной сети.

## Как провести смену

1. Ведущий: **Создать стол** → скопировать ссылку или назвать код.
2. Игроки: открыть ссылку / ввести код и имя.
3. Ведущий может **сесть за стол**, добавить ботов или набрать людей до 5–15.
4. **Начать смену**. Ночью каждый с ролью сдаёт протокол на своём телефоне.
5. Днём — канал, карты, затем голосование в карантин.
6. Если кто-то завис, ведущий закрывает фазу кнопкой внизу.

## Правила, добавленные к заявке

В заявке нет конца партии и части состава. В веб-версии:

| Тема | Решение |
|---|---|
| Мирные | «Сотрудник» без ночного протокола |
| Состав 5–7 | 1 инсайдер; с 6 — белый хакер; с 7 — аналитик |
| Состав 8–9 | + фейкомёт |
| Состав 10–12 | 2 инсайдера + фейкомёт |
| Состав 13–15 | 3 инсайдера + фейкомёт |
| Победа сотрудников | все угрозы в карантине |
| Победа угроз | угроз среди живых ≥ остальных |
| Ничья на совете | карантина нет |
| Резервная копия на угрозу | карта сгорает молча для стола |
| Фишинг | журнал называет адресата, не отправителя |

## Файлы

- `game.py` — механика
- `server.py` — локальный HTTP-стол
- `static/` — интерфейс
- `test_game.py` — автотесты ролей, карт и скрытия секретов

```bat
py -3 -m unittest test_game.py -v
```
