# MAXSPAS Studio — v1 (pre-hybrid)

**Снимок:** 25.06.2026  
**Статус:** архив первой продакшен-версии до перехода на hybrid-дизайн

## Что это

Копия сайта, который был на **maxspas.ru** до промоута `idei/maxspas-hybrid/` в корень:

- 6 страниц: `index`, `services`, `works`, `prices`, `grbnk`, `contacts`
- Стили: `css/style.css`
- Скрипты: `js/layout.js`, `js/animations.js`, `js/cursor-bg.js`, `js/icons.js`

Общие ресурсы (`/assets/`, `/config/site.json`, `/api/`) не дублировались — они остаются в корне репозитория.

## Как открыть локально

Из корня `maxspas-studio` поднимите `serve.bat` и откройте файлы из этой папки через путь  
`http://localhost:5500/archive/v1/index.html`  
(или скопируйте папку отдельно).

## Текущий прод

С **25.06.2026** production = hybrid в корне (`index.html`, `css/site.css`, `js/layout.js` + theme transition).
