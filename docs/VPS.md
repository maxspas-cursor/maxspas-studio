## Важно про «полную власть агента»

Я **не могу** владеть вашим аккаунтом провайдера и платить за вас.  
Удобная схема:

1. Вы регистрируетесь и оплачиваете VPS (карта / СБП).
2. В панели создаёте сервер Ubuntu 22.04/24.04.
3. Добавляете SSH-ключ **или** присылаете IP + пользователя + пароль/ключ **только в чат** (не в git, не в сайт).
4. Я по SSH ставлю Docker/systemd, `.env`, автозапуск ботов, проверяю `/start`.

Владелец всегда вы. У меня — доступ на настройку, пока вы его даёте.

## Рекомендация (дешево + удобно для нас)

### 1-й выбор: [Timeweb Cloud](https://timeweb.cloud/services/vps-linux) · регион **СПб или Москва**

| Параметр | Значение |
|----------|----------|
| Тариф | минимум **1 vCPU / 1–2 GB RAM / 15–30 GB** (~290–450 ₽/мес) |
| ОС | Ubuntu 24.04 |
| Плюсы | РФ (Telegram API стабильнее), почасовка, панель понятная, СБП |
| Хватит на | 1–2 aiogram-бота + запас |

Для двух лёгких ботов **1 GB обычно хватает**; комфортнее **2 GB**.

**Если в корзине ~1000 ₽** — выбрана слишком жирная конфигурация. Урежьте до:
- CPU: **1**
- RAM: **1 GB** (макс. 2 GB)
- Диск: **15–20 GB** NVMe
- Без доп. бэкапов/IP/панелей «для красоты»
- Регион: РФ (СПб/Москва), не Европа

Альтернатива дешевле по факту заказа: [Beget VPS](https://beget.com/ru/vps/custom) от ~**11 ₽/день** (~330 ₽/мес) — тариф с 1 CPU / 1 GB.

### Альтернативы

| Провайдер | Когда брать |
|-----------|-------------|
| [Beget VPS](https://beget.com/ru/vps/custom) | хотите автобэкапы «из коробки», посуточная оплата (~от 11 ₽/день) |
| Aeza / Selectel | если Timeweb недоступен; смотреть цену IPv4 |
| Railway / Render / Fly | удобный деплой из git, но **зарубеж** → часто нужен VPN/прокси до `api.telegram.org` — для вас хуже |

**Не берите** shared-хостинг «сайт за 150 ₽» под Python-бота — неудобно и без нормального long-running процесса.

## Что я поставлю после оплаты (чеклист)

```
Ubuntu → обновления → UFW (22/ssh)
→ Docker или venv
→ репозиторий maxspas-bot (+ 3DGRBNK bot при необходимости)
→ .env: BOT_TOKEN, ADMIN_CHAT_ID (секреты только на сервере)
→ systemd unit: Restart=always
→ проверка: /start в Telegram
→ опционально: fail2ban, бэкап .env в ваше закрытое место
```

Ориентир по времени после доступа: **30–60 минут**.

## Что купить прямо сейчас (коротко)

1. Timeweb Cloud → VPS **СПб**, Ubuntu, **1–2 GB RAM**.  
2. Оплатить месяц (~300–450 ₽).  
3. Написать сюда: **IP**, логин `root`, способ входа (пароль или «ключ добавлен»).  
4. Я поднимаю ботов 24/7.
